# PetrovichParserWoods
Скрипт парсит информацию с раздела сайта https://moscow.petrovich.ru/catalog/95761838/
Сохраняет поля: название, стоимость за шт в csv файл


## Установка:
Требуется Python версии 3.11.0

## Скачать зависимости командой:
```
pip install -r requirements.txt
```

## Запуск

Запустить 
petrovich_parser_woods.py
